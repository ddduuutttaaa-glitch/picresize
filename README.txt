Passport Photo Camera - installable app (PWA)

1. Upload ALL files in this folder to any free HTTPS host, e.g.
   - Netlify Drop (app.netlify.com/drop): drag the folder in
   - Cloudflare Pages, GitHub Pages, or Firebase Hosting
2. Open the https:// link on your phone in Chrome (Android) or Safari (iPhone).
3. Android: menu > Install app. iPhone: Share > Add to Home Screen.
After the first visit it opens full-screen and works offline.
